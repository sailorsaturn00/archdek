# ArchDek
### Architectural Echoes of Brutalism

ArchDek is an open architectural atlas designed to explore,
map, and preserve architectural heritage worldwide.

This first release focuses on Brutalism as a curated layer,
with future expansion planned for additional architectural styles.

## Features
- 🌍 Global interactive map
- 🔥 Density heatmaps
- ⭐ Favorites, visited & wishlist
- 🔍 Search by name or architect
- 📍 Nearby architecture discovery
- 📱 Progressive Web App (PWA)

## Data
Architectural data is released as open data under
Creative Commons Attribution 4.0 (CC BY 4.0).

## Code
The application source code is source-available
and restricted to non-commercial use.
